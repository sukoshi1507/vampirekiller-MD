Les objets de butin24h/26h possèdent une représentation/réservation C800 dans le MSX, alors que le port transfère l'événement vers la file de drops de candles.c. Leur durée de réservation, l'intégralité des octets IX conservés après transfert et l'occupation de pool correspondante ne sont pas reproduites. Les traces longues signalent explicitement24 échantillons de réservations24h/26h non représentées ; les octets résiduels d'objets déjà inactifs sont également exclus et comptés. Aucun résultat «32 octets égaux» n'est annoncé pour ces états. Le code `enemies_death.inc` est marqué PROVISIONAL. Le ramassage complet de tous les butins en situation réelle et les saturations combinées restent à traiter ; le LOT10 n'est donc pas déclaré intégralement clos.
